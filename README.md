# M Platform

منصة شراء وطلبات عروض أسعار متعددة الواجهات، مع تطبيق جوال Capacitor وخادم API مشترك.

## الحالة الحالية

المشروع مربوط فعليًا بـ GitHub وVercel وSupabase، وتُطبق ترحيلات قاعدة البيانات على المشروع التشغيلي. واجهة المستخدم الوحيدة المعتمدة موجودة داخل `mobile-app/` وتُستخدم نفسها على iOS وAndroid والويب، ثم تُبنى إلى `dist/` للنشر على Vercel.

المصدر هو المرجع. مجلد `dist/` ناتج build ولا يُعدّل أو يُحفظ يدويًا.

## المجلدات الرئيسية

```text
M-Platform/
├── mobile-app/         الواجهة الموحدة للعميل/المورد/الإدارة على الجوال والويب
├── backend/            API والمصادقة والأعمال والفواتير والإشعارات
├── database/           ترحيلات PostgreSQL
├── api/                نقطة دخول Vercel
├── scripts/            build وفحوص المصدر
├── tests/              اختبارات backend
└── docs/               توثيق المشروع
```

## أوامر التحقق

```bash
npm test
npm run check
npm run build

cd mobile-app
npm ci
npm test
npm run build
npx cap sync ios
```

GitHub Actions يشغّل فحوص backend، بناء تطبيق الجوال، اختبارات layout على Chromium/WebKit، وتجميع iOS بدون توقيع.

## ملاحظات مهمة

- لا تحفظ أسرار Supabase أو مفاتيح الخدمة داخل المستودع.
- جلسات الويب والجوال تمر عبر API والتحقق من الدور على الخادم.
- الفواتير تحفظ snapshot للعملة وسعر الصرف عند الإصدار.
- إشعارات الجرس داخل التطبيق فعالة. بنية Push الخارجية موجودة، لكن لا تعتبر APNs/FCM مكتملة حتى يوجد تسجيل جهاز ومرسل فعلي للـ outbox.
- قبل أي إصدار إنتاجي للجوال يجب أن تكون GitHub Actions خضراء على commit المراد تثبيته.
