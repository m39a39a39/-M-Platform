# M Platform

مشروع منصة طلبات عروض أسعار بالعربية والإنجليزية، بواجهات منفصلة وخادم مشترك.

**حالة هذه الحزمة:** تم إعداد الكود وملفات الربط. لم تُشغّل فحوص النسخة الجديدة بناءً على طلب المستخدم، ولم تُطبّق الترحيلات على Supabase ولم يُنشر المشروع. يلزم إكمال إعداد الخدمات والتحقق من دورة العمل قبل استقبال مستخدمين حقيقيين.

## ترتيب الملفات

```text
M-Platform/
├── customer-web/       صفحة العميل والتسجيل ومنطق واجهته
├── supplier-web/       صفحة المورد والتسجيل ومنطق واجهته
├── admin-dashboard/    المراجعة والترجمة والفريق والصلاحيات
├── backend/            API والمصادقة والطلبات والعروض والصور
├── database/           ترحيلات PostgreSQL وإنشاء المدير الرئيسي
├── shared/             الصفحات العامة وCSS وأدوات الواجهات المشتركة
├── docs/               إعداد الخدمات وشرح API وحدود النسخة
├── api/                نقطة دخول Vercel التي تستدعي backend
├── scripts/            تجميع الملفات وفحصها عند السماح بذلك
├── tests/              فحوص محضّرة، غير مشغّلة لهذه الحزمة
├── dist/               نسخة مجمعة من الواجهات، لا تعدّلها مباشرة
├── .env.example        أسماء متغيرات الاتصال دون أي أسرار
└── vercel.json         إعداد Vercel
```

ابدأ بملف [تعليمات التشغيل](docs/SETUP-AR.md). تفاصيل التصميم في [البنية](docs/ARCHITECTURE-AR.md)، وحدود التحقق في [حالة التسليم](docs/DELIVERY-STATUS.md).

## التعديل

عدّل الملفات في مجلد القسم المعني، ثم اجمع الواجهات:

```bash
npm run build
```

الأمر ينسخ صفحات الأقسام وملفاتها المشتركة إلى `dist` مع الحفاظ على روابط الصفحات الحالية. الخادم وقاعدة البيانات لا يُنسخان إلى مجلد الويب العام.

**هذه النسخة لا تعمل بمجرد النقر على HTML من Finder.** افتحها من الخادم المحلي بعد إعداد Supabase. لم نعد نخزن الحسابات والطلبات في localStorage؛ يستخدم التخزين المحلي لتفضيل اللغة فقط.

لا يوجد حساب إدارة أو كلمة مرور افتراضية. تسجيل الدخول الحقيقي وإدارة كلمات المرور من خلال Supabase Auth.
