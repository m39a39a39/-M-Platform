# حالة التسليم الحالية

## يعمل حاليًا

- GitHub هو مصدر الكود الرئيسي.
- Vercel ينشر نفس واجهة `mobile-app` المستخدمة في التطبيق ويشغل API.
- Supabase Auth وPostgreSQL وStorage مربوطون بالمشروع التشغيلي.
- تطبيق Capacitor للجوال موجود لـ iOS وAndroid.
- فصل صلاحيات العميل والمورد والإدارة وتخفيف بيانات الهوية حسب الدور.
- RFQ والعروض العامة وطلبات السلة ومتابعة الطلبات.
- إعادة إسناد المورد عند تعذر التنفيذ، مع موافقة العميل عند تغير الشروط.
- فواتير Proforma وFinal PDF مع snapshot للعملة وسعر الصرف.
- إيصالات الدفع ومراجعة الإدارة.
- العملات المُدارة يدويًا وتفضيل عملة العميل.
- إشعارات داخل التطبيق للعميل والمورد والإدارة بحسب الأحداث المدعومة.

## يحتاج مراقبة أو تطوير لاحق

- Push الخارجية: الجداول وAPI موجودة، لكن APNs/FCM وإرسال outbox لا يعتبران مكتملين حاليًا.
- أزيلت الواجهات الويب القديمة المنفصلة؛ الويب والجوال الآن يبنيان من نفس مصدر `mobile-app`.
- `/api/state` ما زال يعتمد على snapshots كبيرة نسبيًا؛ قبل التوسع الكبير نحتاج pagination وبحثًا على الخادم.
- نحتاج إبقاء اختبارات دورة المورد البديل والعملات والفواتير ضمن CI مع كل تعديل مستقبلي.

## معيار الإصدار
