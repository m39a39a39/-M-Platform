# إعداد M Platform على GitHub وVercel وSupabase

هذه تعليمات الخطوة التالية؛ لم يتم إنشاء الخدمات أو نشرها بالنيابة عنك. يلزم استخدام حساباتك. لا تضع مفاتيح الخادم في المحادثة أو في ملفات الواجهة.

## 1. Supabase

1. أنشئ مشروع Supabase جديدًا. اختر منطقة قريبة من الأسواق المستهدفة، ثم اختبر الوصول من الصين والسعودية والإمارات عند التشغيل.
2. افتح SQL Editor وشغّل `database/migrations/001_initial.sql` مرة واحدة فقط. هذه الترحيلة مخصصة لمشروع جديد، وليست لاستبدال قاعدة بيانات قائمة.
3. الترحيلة تنشئ الجداول وRLS ومجلد الصور الخاص `m-private` وسجل الإجراءات والإشعارات.
4. من إعدادات API خذ Project URL و`anon` key و`service_role` key. هذه النسخة تستخدم مفاتيح Supabase التقليدية التي تدعم طلبات REST، ولا تضع `service_role` في المتصفح.
5. أبقِ تأكيد البريد الإلكتروني مفعّلًا. اضبط Site URL على عنوان الموقع الذي ستستخدمه. يتم تأكيد البريد بواسطة رابط Supabase ثم يسجل المستخدم الدخول بكلمة مروره من صفحة الموقع.
6. للإطلاق العام اضبط إرسال البريد من خلال SMTP الخاص بك وحدود التسجيل ومحاولات الدخول في إعدادات Supabase Auth. راجع الحدود والباقات المتاحة في حسابك؛ الحزمة لا تضمن أن تشغيل مشروع تجاري سيكون مجانيًا.

## 2. التشغيل المحلي على الماك

ثبّت Node.js إصدار 22 حديثًا أو أحدث. لا توجد حزم npm خارجية مطلوبة لهذه النسخة؛ الخادم يستخدم fetch المدمج وواجهات Supabase HTTP.

افتح Terminal داخل مجلد المشروع:

```bash
cp .env.example .env
```

عدّل `.env` على جهازك:

```dotenv
SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVER_ONLY_SERVICE_ROLE_KEY
APP_ORIGIN=http://localhost:3000
PORT=3000
```

ثم:

```bash
npm run build
npm run dev
```

افتح `http://localhost:3000`. إبقاء APP_ORIGIN مطابقًا تمامًا لعنوان الموقع، دون شرطة مائلة أخيرة، مطلوب لحماية عمليات الكتابة. استخدم localhost نفسه، لا عنوان IP مختلفًا.

## 3. المدير الرئيسي

1. سجل حسابًا عاديًا باسمك وبريدك من الموقع، ثم أكد البريد.
2. افتح `database/bootstrap-owner.sql` واستبدل `REPLACE_WITH_YOUR_EMAIL` ببريدك.
3. شغّل الملف في SQL Editor مرة واحدة. لن ينشئ كلمات مرور ولن يسمح بإنشاء مدير رئيسي ثانٍ بهذه الطريقة.
4. سجّل الخروج ثم الدخول. يوجّهك الموقع إلى لوحة الإدارة حسب الدور المحفوظ في قاعدة البيانات.
5. لإضافة مدير آخر: يسجل الشخص حسابًا ويؤكد بريده أولًا، ثم تضيف بريده وتحدد صلاحياته في «فريق الإدارة». هذا المسار لا يرسل دعوة بريدية آلية؛ يعتمد على حساب موجود.

المدير الرئيسي محمي من التعديل والحظر عبر API. مدير الفريق لا يستطيع منح صلاحيات لا يملكها أو تعديل نفسه.

## 4. GitHub

1. أنشئ مستودعًا خاصًا باسم M-Platform.
2. ارفع مجلدات المصدر وملفات الإعداد، بما فيها `.gitignore` و`.env.example`.
3. لا ترفع `.env` أو أي مفاتيح فعلية أو بيانات مستخدمين.
4. ترحيلات SQL التالية تُضاف كملفات جديدة متسلسلة. لا تعدّل الترحيلة الأولى بعد تطبيقها على قاعدة حقيقية.

لم يتم إنشاء مستودع GitHub أو رفع هذا المشروع إلى حسابك ضمن التسليم.

## 5. Vercel

1. استورد مستودع GitHub من حسابك في Vercel.
2. اختر إعداد مشروع Other/بدون إطار عمل، وجذر المشروع هو المجلد الذي يحتوي `package.json`.
3. أمر البناء `npm run build`، ومجلد الواجهة `dist`، ونسخة Node حديثة توافق `package.json`.
4. أضف متغيرات Supabase الثلاثة وAPP_ORIGIN في إعدادات Environment Variables للخادم. لا تستخدم أسماء تبدأ بـNEXT_PUBLIC أو VITE لمفتاح الخدمة.
5. اضبط APP_ORIGIN على عنوان HTTPS الفعلي، مثل عنوان الإنتاج الذي تمنحه Vercel أو الدومين الخاص بك.
6. حدّث Site URL في Supabase إلى العنوان نفسه ثم أعد النشر بعد تغييرات المتغيرات.
7. `api/index.js` هو Vercel Function، وتحوّل قواعد `vercel.json` الطلبات `/api/*` إليه. يبقى منطق العمل في `backend/`.

معاينات Vercel المتغيرة تحتاج APP_ORIGIN مطابقًا لعنوان المعاينة. استخدم قاعدة بيانات اختبار مستقلة للمعاينات ولا تربطها ببيانات العملاء الحقيقية.

اختيار الخطة المدفوعة أو المجانية يجب أن يراعي شروط الاستخدام التجاري والحدود الفعلية في Vercel وSupabase، لا عدد المستخدمين وحده.

## 6. التحقق بعد الإعداد

عند السماح بتشغيل الفحوص:

```bash
npm run check
npm test
```

هذه الفحوص المحضرة لا تغني عن تجربة التكامل الفعلي: تسجيل عميل وموردين، إنشاء طلب بصور، الترجمة اليدوية، دعوة مورد واحد، تقديم ونشر عرض، اختيار عرض مرة واحدة، اختبار الحظر والمحذوفات ومدير محدود الصلاحيات. يجب أيضًا التأكد من أن مفتاح anon لا يستطيع قراءة الجداول أو الصور مباشرة.

ملف `docs/DELIVERY-STATUS.md` يحدد ما لم يُختبر في هذه الحزمة.
